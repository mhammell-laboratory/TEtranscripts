# Legacy DESeq2 versus Python-native comparison

These results were recorded from [GitHub Actions run 31231301841](https://github.com/molikd/TEtranscripts/actions/runs/31231301841) on 2026-08-08. The legacy result was generated by the exact `write_R_code()` function from commit `32426b94d2d8ed0ebaca011feec86cc62df61e6c`; its emitted script was run with R 4.3.3. Both paths used `small_counts.cntTable` with three treatment and three control replicates.

This is a compatibility test, not a claim of numerical identity with the full DESeq2 package.

The sole call difference was `up_moderate_gene`, which straddled the strict fold-change boundary: DESeq2 reported log2 fold change 1.000 while the native implementation reported 0.989. Both implementations assigned it a highly significant adjusted p-value and agreed on its direction. Thus, this was a threshold-edge difference rather than a contradictory biological result.
